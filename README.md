## 📚 Danh sách Bài tập / Dự án

Portfolio bao gồm 6 bài tập cốt lõi minh chứng cho năng lực số và ứng dụng AI có trách nhiệm:

1. **Bài tập 01: Thao tác cơ bản với Tệp tin & Thư mục**
   - Thiết lập cấu trúc thư mục phân cấp và áp dụng quy tắc đặt tên chuẩn (PascalCase).
2. **Bài tập 02: Tìm kiếm & Đánh giá Thông tin Học thuật**
   - Sử dụng toán tử tìm kiếm nâng cao để tra cứu thông tin chuyên sâu (Fragile Base Class trong Java).
3. **Bài tập 03: Viết Prompt Hiệu quả cho Tác vụ Học tập**
   - Ứng dụng kỹ thuật Prompt Engineering (Role-playing, Chain-of-thought, Constraints).
4. **Bài tập 04: Hợp tác Trực tuyến trong Dự án Nhóm**
   - Quản lý công việc và giao tiếp thông qua Trello (Kanban), Discord và Google Workspace.
5. **Bài tập 05: AI Tạo sinh Hỗ trợ Sáng tạo Nội dung**
   - Tích hợp Gemini, DALL-E 3 và Canva AI để sản xuất nội dung Infographic học thuật.
6. **Bài tập 06: Sử dụng AI Có Trách nhiệm**
   - Xây dựng bộ nguyên tắc cá nhân trong học thuật, kiểm chứng kết quả và bảo vệ toàn vẹn dữ liệu.

## 💻 Cài đặt & Chạy Local

Nếu bạn muốn chạy source code này trên máy tính cá nhân:

1. **Clone repository:**
   ```bash
   git clone https://github.com/Thaisodupe-coder/Thaisodupe-coder.github.io.git
   ```
2. **Di chuyển vào thư mục project:**
   ```bash
   cd Thaisodupe-coder.github.io/project
   ```
3. **Cài đặt dependencies:**
   ```bash
   npm install
   ```
4. **Chạy development server:**
   ```bash
   npm run dev
   ```
   Sau đó mở trình duyệt tại `http://localhost:5173` (hoặc cổng tương ứng hiện trên terminal).
